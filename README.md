- Проект выполнен на версии Unity 2022.3.62f2
- В проекте используется Zenject, DoTween, Unity Localization + Google SpreadSheets, UnityMCP, сторонние ассеты для VFX и звуки с freesound.org
- Графика был взята с тестового задания из Figma и обработана для сокращение размера и количества изображений

Основной геймплей и элементы игры:
- Нижняя полоса - палитра с кубами, откуда можно с помощью Drag and Drop брать кубы для размещения в башне.
- Права часть - башня, где можно располагать кубы и впоследствии их забирать
- Левая часть - дыра, в которую можно бросать кубы только из башни. В рамках тестового реализацию броска кубов из палитры в дыру не делал.
- Во время любых анимаций блокируется взаимодействие с кубами, чтобы не было возможности сломать игру
- Добавил логотип и сплэш лого JustMoby
- Keystore и креды от Google SpreadSheets в репозиторий не заливал. Они будут отдельной ссылкой.э
